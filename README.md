# Life Decision Skill

> 一个让 AI 帮你把人生大选择想清楚的中文 Skill。

不是替你决定，也不是算命。它的用途是：当你在“换不换工作、去不去别的城市、要不要创业、要不要报课、要不要花一大笔钱”之间纠结时，先把现实情况理清，再给你一条能执行、能止损的路。

## 它会怎么帮你

可以把它理解成一个不会急着劝你的决策助手：

1. **先问清楚**：你有哪些选项、什么时候必须决定、最怕损失什么。
2. **先算账**：只要事情涉及钱，就算你最多能撑多久。
3. **再反复推演**：把每条路可能发生的好结果、坏结果和转弯点放进模拟里，多次计算比较。
4. **最后给行动**：告诉你哪条路更稳、哪条路你现实里更可能走、什么时候该停损。

它不会在后台无限演算。每次分析时才会运行一次：先检查信息和预算，再做多轮模拟；分析结束就停。

## 那个“反复演算 / 验证”到底是什么？

有两层：

- **验证**：资料够不够？钱够不够？如果这些没弄清，Skill 不会硬给结论。
- **推演**：同一个选择不只算一次。它会模拟很多条可能的后续路径，既看“理论上最好的选择”，也看“按一个人真实的习惯，最可能走成什么样”。

所以它给的不是一句“你应该选 A”，而是类似：

> A 的总体风险更低；但你容易因为压力放弃 A。先用两周小试，现金低于某条线就停，效果达到某个指标再继续。

这就是“不断演算”的意义：不是追求神准，而是把容易忽略的坏情况提前看见。

## 适合问什么

- 我该换工作，还是先稳住？
- 要不要去深圳／东莞／别的城市？
- 要不要裸辞、创业或报培训班？
- 学历、考证、技能学习该怎么排？
- 一笔大消费到底买不买？
- 两段关系或两个家庭方案怎么比较？

## 它不适合什么

- 自伤、自杀、暴力、胁迫、诈骗等紧急情况：先找现实中的人和专业支持，不做推演。
- 想让它替你承担决定。
- 把模拟结果当成命运预言。

## 最简单的使用方式

把这个目录放进支持 Skills 的 AI 工具里，然后直接说：

```text
我在纠结要不要从佛山去深圳做文员。
我手里有 1 万元，每月必要花费约 3000 元，最晚两个月内要决定。
```

Skill 会先追问缺失的关键事实。资料足够后，才会开始预算和推演。

## 如果你想自己运行

只需要 Python 3，不需要额外安装包：

```bash
git clone https://github.com/zhuangsCC/life-decision-skill.git
cd life-decision-skill
python3 scripts/mcts_sim.py --example --iters 200 --sims 50 --months 3
```

这条命令运行的是虚构案例，只用来确认程序正常。
