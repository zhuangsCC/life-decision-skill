# 预算、外部环境与评分聚合

本文件用于缺口分析、自评校准、外部环境采集、财务跑道、三档预算压力测试，以及从详细打分聚合到核心参数。涉及工作、城市、创业、转行、学习投入、搬家、负债、家庭支持时必须读。

### 第二阶段：缺口分析（收集率接近 85% 时）

当收集率达到 70%-85% 区间时，进行一次内部缺口分析：

- 哪些维度虽然整体收集率还行，但**关键子项**缺失？
- 有没有信息之间存在矛盾？（比如用户说"我很看重家庭"但又说"父母关系很差不想回家"）
- 有没有用户**没提到但应该很重要**的因素？（比如面临跳槽决策但完全没提经济压力或家庭负担）

把这些发现转化为追问，补到 85% 以上。

### 第二阶段（续）：自评校准（防主观偏差，强制）

信息够了不代表打分准。大模型对用户各维度的打分（技能水平、自律、抗压能力等）是基于聊天推断的**主观判断**，可能偏差很大。必须在跑模拟之前让用户校准。

**执行方式**：把关键维度的AI打分展示给用户，用具体描述而非抽象数字：

```
我根据你的情况做了初步评估，你看看准不准：

1. 你的技术水平 — 我觉得算中上（能做Rust编译+飞书集成，非科班但实战强）
2. 你的自律程度 — 今年开窍后不错，但以前有拖延习惯，算中等
3. 你的抗压能力 — 焦虑明显但没崩盘，算中等偏下
4. 你的社交能力 — 你自己说独狼型，不擅长推销
5. 你的财务状况 — 零存款，完全靠妈妈

有没有哪个你觉得我判断错了？说具体事实就行，我来调。
```

**规则**：
- 用户纠正的，按用户的说法调分（用户说"我其实挺自律的，每天学8小时"→自律上调）
- 差异超过15分的维度，追问一个具体事实来校准（"你说你自律，能举个最近的例子吗？"）
- 校准后的分数才进入填空表

### 第三阶段：外部环境数据采集（强制联网，不可跳过）

**这一步的顺序是"自上而下"：先看时代大势，再一层层落到个人。** 个人情况再好，不看大环境等于盲人摸象——同一个人 2008 年和 2025 年做同样的决策，答案完全不同，因为"时代的水位"变了。先量水位，再看个人站在哪。

**⚠️ 两条硬规则（违反等于误导用户）：**
1. **所有数字必须现场联网搜、并标注来源和日期；禁止凭记忆写、禁止把往年数字当现在用。** LLM 记忆里的宏观数字会过期，张口就来=误导（铁律二同款精神）。
2. **预测类数字（如"3年后起薪"）必须标"这是带不确定性的估计"，不能当既成事实。**

**L0 - 时代定位（最顶层，定底色，在下面 M1–M6 之上）**
- 我们处在什么时代？AI 革命到哪一步、全球化在退潮还是加速、人口是增是减、经济在上行还是下行周期、哪些技术浪潮在起。
- 这一层决定后面所有分析的"底色"——传统路径（考好大学→进大厂→稳定升职）是否还成立。

**必须搜索的数据维度（按决策类型选取相关项）：**

**M1 - 国家政策与法规**
- 与用户决策直接相关的国家政策（如房地产政策、税收政策、行业监管、就业政策）
- 近期政策风向（鼓励/限制/中性）
- 未来 1-3 年政策预期方向

**M2 - 宏观经济环境**
- 中国 GDP 增速趋势、CPI/PPI 数据
- 美国经济指标及对中国的影响（美联储利率政策、汇率走势）
- 全球经济形势（衰退/复苏/过热）
- 就业市场整体状况（失业率、招聘趋势）

**M3 - 行业与市场**
- 用户所在行业或目标行业的发展趋势
- 行业薪资水平和增长预期
- 行业风险因素（裁员潮、技术替代、监管变化）
- 相关股市板块表现（如适用）

**M4 - 城市与生活成本**
- 用户所在城市的物价水平、房租/房价趋势
- 城市发展前景（人口流入/流出、产业政策）
- 生活成本 vs 收入的比值

**M5 - 股市与资本市场信号**（如决策涉及投资/财务）
- 大盘走势和关键指标
- 相关板块和个股表现
- 市场情绪指标

**M6 - 国际局势与风险**
- 中美关系现状及对相关行业的影响
- 地缘政治风险（如影响供应链、外贸等）
- 全球技术趋势（AI 发展、新能源等）

**执行方式**：使用 WebSearch 工具搜索以上信息，每个维度至少搜索 2-3 次获取不同来源的数据。搜索关键词要具体，不要泛泛搜"经济怎么样"，而是搜"2026年中国GDP增速预测"、"深圳房租走势2026"、"AI行业裁员趋势2026"这种具体问题。

**⚠️ 外部环境量化评分（走代码）**

采集完外部数据后，用 Python 代码对每个维度打分（0-100），并给出综合外部环境评分：

```python
# 外部环境评分示例
macro_scores = {
    "国家政策": {"score": 72, "weight": 0.20, "reason": "AI行业政策鼓励，但监管趋严"},
    "宏观经济": {"score": 58, "weight": 0.20, "reason": "GDP增速放缓至4.8%，消费复苏但不均衡"},
    "行业趋势": {"score": 81, "weight": 0.25, "reason": "AI行业高速增长，人才需求旺盛"},
    "城市成本": {"score": 45, "weight": 0.15, "reason": "深圳房租同比上涨8%，生活成本高"},
    "资本市场": {"score": 65, "weight": 0.10, "reason": "科技板块震荡，AI概念分化"},
    "国际局势": {"score": 50, "weight": 0.10, "reason": "中美科技脱钩风险持续，但国内替代需求大"},
}

total = sum(d["score"] * d["weight"] for d in macro_scores.values())
print(f"外部环境综合评分: {total:.1f}/100")
for name, d in macro_scores.items():
    print(f"  {name}: {d['score']}分 (权重{d['weight']:.0%}) — {d['reason']}")
```

**⚠️ 财务倒计时（走代码，强制输出）**

个人评分出来后，必须算一条"财务跑道"——用户在当前消耗速度下还能撑多久。这个数字直接决定他有没有时间窗口去尝试高风险选项。

```python
# 财务跑道计算
finances = {
    "可用现金": 0,           # 手上有多少钱（元）
    "可变现资产": 3000,      # 能快速变现的东西（如显卡）
    "月固定收入": 0,         # 稳定进账（工资/补贴）
    "月必要支出": 0,         # 在妈妈家吃住=0；在外租房=房租+饭钱
    "月心理消耗系数": 1.5,   # 焦虑状态下实际消耗比账面上快（1.0=正常, 1.5=焦虑, 2.0=濒临崩溃）
}

total_runway = finances["可用现金"] + finances["可变现资产"]
monthly_burn = max(0, (finances["月必要支出"] - finances["月固定收入"])) * finances["月心理消耗系数"]

if monthly_burn > 0:
    months = total_runway / monthly_burn
    print(f"财务跑道: {months:.1f}个月（资产{total_runway}元 ÷ 月消耗{monthly_burn:.0f}元）")
else:
    # 月支出被家人cover的情况
    months = float("inf")
    print(f"财务跑道: 理论上无限（家人cover基本开支），但心理压力在累积")
    print(f"心理跑道: 建议设一个自定期限（如2-3个月），超期没进展就切换策略")

# 决策影响
if monthly_burn > 0 and months < 2:
    print("⚠️ 跑道不足2个月 → 高风险选项（自由职业/创业）不可行，必须先稳住现金流")
elif months < 6:
    print("⚠️ 跑道不足6个月 → 可以试高风险但必须设止损点")
else:
    print("✅ 跑道充足，有时间窗口尝试")
```

**⚠️ 预算推演增强：三档压力测试（强制）**

财务倒计时不能只算一个"平均月消耗"。现实里最容易翻车的是：临时支出、收入延迟、家里支持中断、心理状态恶化。必须把预算拆成三档跑：

```python
# 预算三档压力测试
budget = {
    "可用现金": 0,
    "可快速变现资产": 3000,
    "月稳定收入": 0,
    "月必要支出": {
        "房租": 0,
        "吃饭": 0,
        "交通": 0,
        "通讯": 0,
        "债务最低还款": 0,
        "医疗药物": 0,
        "家庭固定责任": 0,
    },
    "月可压缩支出": {
        "娱乐": 300,
        "学习订阅": 200,
        "社交": 200,
    },
    "一次性即将发生支出": {
        "搬家押金": 0,
        "培训/考试": 0,
        "设备维修": 0,
    },
    "家人支持": {
        "每月支持": 0,
        "可持续月数": 0,  # 不确定就填保守值
        "中断风险": 0.3,  # 0=几乎不会中断, 1=随时可能中断
    },
}

cash = budget["可用现金"] + budget["可快速变现资产"]
one_off = sum(budget["一次性即将发生支出"].values())
necessary = sum(budget["月必要支出"].values())
compressible = sum(budget["月可压缩支出"].values())
income = budget["月稳定收入"]
family = budget["家人支持"]["每月支持"]

scenarios = {
    "乐观": {"income_factor": 1.0, "expense_factor": 0.9, "family_factor": 1.0, "shock": 0},
    "正常": {"income_factor": 1.0, "expense_factor": 1.0, "family_factor": 0.8, "shock": one_off},
    "保守": {"income_factor": 0.7, "expense_factor": 1.2, "family_factor": 0.3, "shock": one_off + 1000},
}

for name, s in scenarios.items():
    monthly_income = income * s["income_factor"] + family * s["family_factor"]
    monthly_expense = necessary * s["expense_factor"] + compressible * 0.5
    burn = max(0, monthly_expense - monthly_income)
    usable_cash = max(0, cash - s["shock"])
    months = float("inf") if burn == 0 else usable_cash / burn
    months_text = "无限/不烧钱" if months == float("inf") else f"{months:.1f}个月"
    print(f"{name}: 可用现金{usable_cash:.0f}元, 月净消耗{burn:.0f}元, 跑道{months_text}")

    if months != float("inf") and months < 2:
        print("  -> 红灯：必须先找现金流，不允许裸辞/全职创业/长期备考")
    elif months != float("inf") and months < 6:
        print("  -> 黄灯：可以试错，但必须有周级止损点和最低收入来源")
    else:
        print("  -> 绿灯：有试错窗口，但仍要定复盘点")
```

**预算输出必须包含：**
- 基础账：可用现金、可变现资产、月稳定收入、月必要支出、月可压缩支出、一次性支出。
- 三档结果：乐观/正常/保守分别还能撑多久。
- 红黄绿灯：少于2个月=红灯，2-6个月=黄灯，超过6个月=绿灯。
- 止损线：现金低于多少、多久没收入、投递/项目多少次无反馈，就切换策略。
- 不确定项：任何用户说"不知道/差不多"的数字，必须标为估算，并用保守档压测。

**两个评分都出来后，进入评分聚合和蒙特卡洛模拟。**

### 第三阶段（续）：评分聚合 — 从详细打分到核心参数

30 多个子项的详细打分不是全部直接拿去模拟。先聚合成 **7 个核心参数**，这些参数才是模拟的输入。

**个人侧聚合为 4 个核心参数（走代码）：**

```python
# 从详细子项聚合为核心参数
# 大模型根据收集到的信息填入各子项得分（0-100），代码负责聚合计算

personal_raw = {
    # D3 个人画像
    "年龄": 28, "学历": 75, "技能水平": 80, "健康状况": 90,
    # D4 家庭背景
    "父母收入": 60, "家庭负债": 20, "家庭关系": 80, "赡养压力": 30,
    # D5 当前状态
    "存款": 50, "月收入": 55, "月支出": 65, "工作稳定性": 70,
    # D6 过往经历
    "决策经验": 60, "抗压能力": 65,
    # D2 价值观
    "风险偏好": 55, "家庭优先度": 70, "成长渴望度": 80,
}

# 聚合公式（代码执行，大模型不心算）
core_params = {
    "安全垫厚度": (
        personal_raw["存款"] * 0.30 +
        (100 - personal_raw["家庭负债"]) * 0.25 +  # 低负债=高安全
        personal_raw["父母收入"] * 0.20 +
        (100 - personal_raw["赡养压力"]) * 0.25     # 低压力=高安全
    ),
    "能力弹药库": (
        personal_raw["学历"] * 0.20 +
        personal_raw["技能水平"] * 0.40 +
        personal_raw["决策经验"] * 0.20 +
        personal_raw["抗压能力"] * 0.20
    ),
    "方向清晰度": (
        personal_raw["风险偏好"] * 0.30 +
        personal_raw["家庭优先度"] * 0.30 +
        personal_raw["成长渴望度"] * 0.40
    ),
    "时间窗口": max(10, 100 - personal_raw["年龄"]) * 0.01 * (
        personal_raw["健康状况"] * 0.50 +
        personal_raw["抗压能力"] * 0.30 +
        (100 - personal_raw["赡养压力"]) * 0.20
    ) / 100 * 100,  # 归一化到0-100
}

for name, score in core_params.items():
    print(f"{name}: {score:.1f}/100")
```
