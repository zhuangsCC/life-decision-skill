# 信息收集与深挖

本文件用于 life-decision 的第零阶段、第一阶段和第 1.5 阶段。凡是用户提出人生选择、职业选择、城市选择、创业/转行/备考/关系选择，必须先读本文件，再开始首轮追问。

## 信息收集体系

### 维度与权重

每个维度包含若干子项。每个子项状态为：
- ✅ 已知（用户明确说过）= 1.0
- 🟡 部分已知（暗示过但不确定）= 0.5
- ❌ 未知（完全没提到）= 0

维度得分 = 该维度下已知子项得分之和 / 子项总数
总收集率 = Σ(维度得分 × 维度权重)

### 追问的方法（比"问什么"更重要——这里是整个skill最难做好的地方）

**方法一 · 反推法：问具体事实，不问抽象自评。** 一律问**具体的、用户能张口就答的事实**，再由你从这些事实**反推**出 TRAITS/params——比让用户自评准得多。
- ❌ "你的风险偏好打几分？" → ✅ "上次有机会但有风险的事，你是冲了还是退了？"
- ❌ "你自律吗？" → ✅ "你定的计划，一般能坚持几天？"

**方法二 · 每个问题都要有"去向"。** 问之前先想：这个答案最后填进填空表的哪个格子（哪个 param / tag / 概率 / 可行性条件）。问不出去向的问题，就别问。

**方法三 · 剥洋葱法：同一个话题至少剥三层。** 用户给的第一层答案几乎永远是"表面版"——不是撒谎，是人天然会给出"社会期望"或"自我期望"的回答。你要往下剥：
- **第一层（表面回答）**："我想找份AI开发的工作"
- **第二层（追问动机）**："为什么是AI开发而不是其他技术岗？"→ "因为我觉得AI是未来"
- **第三层（追问真实驱动）**："你说AI是未来——但6家公司要了简历零面试，你有没有一瞬间想过'也许不是AI的问题，是我简历的问题'？"→ 这里开始出真东西了
- **第四层（追问恐惧）**："如果继续投下去还是没人要，你最怕的不是找不到工作，还是别的什么？"→ "最怕的是证明自己真的不行"

剥到第三层第四层才算真正理解这个人。停在第一层就填数字=误诊。

**方法四 · 读空气：听他没说出口的东西。** 人在聊天时会泄露大量"自己没意识到在说"的信息。你要训练自己捕捉这些信号：
- **反复提的事 = 真正在意的。** 如果他三次提到"没有学历"，说明学历焦虑比他承认的更深。
- **突然转移话题 = 碰到了痛处。** 你问家庭他突然聊工作，说明家庭那块有不想说的东西。
- **过度解释 = 自我说服。** "我其实什么都愿意做的"说一遍够了，反复强调说明他自己也不确定。
- **具体 vs 模糊。** 说"我做了飞书机器人、用Rust编译TS、改了Claude Code"——这是真有料。说"我学了很多AI技术"——可能是学了但没做出东西。
- **语气变化。** 聊某件事突然变低落/变激动，追一句"说到这个你好像有点……"。

**方法五 · 矛盾追踪：嘴上说的 vs 实际做的。** 人几乎都有"说一套做一套"的地方，这不是虚伪，是人的自我认知和行为之间有落差。这个落差恰恰是性格推演最需要的输入：
- 他说"什么都愿意做" → 但实际投简历只投AI岗，文员做3天被炒 → 他的"愿意"有边界
- 他说"独狼不需要别人" → 但他投了6家公司希望被看见、找你来测试希望被理解 → 他需要连接但不知道怎么获取
- 他说"愿意承担风险" → 但他从深圳退回佛山 → 他的风险承受力没有他以为的那么高

**遇到矛盾不要直接指出**（会被防御），而是用"我注意到你前面说A，但后来好像B？"的方式让用户自己解释。解释本身就是宝贵的信息。

**方法六 · 模式识别：从他过去的故事里找"反复出现的循环"。** 人的行为有很强的pattern——同一个人在不同场景下会反复犯同一类错误或做出同一类选择。你需要从过往经历中识别出这个pattern：
- 他是不是总是"冲出去→碰壁→退回安全区→重新攒能量→再冲出去"？（循环型）
- 他是不是总是在"快要成功的时候放弃/出岔子"？（自我设限型）
- 他是不是总是在"别人帮他做了决定后才行动"？（被动等待型）
- 他是不是"同时开很多头但很少收尾"？（启动者型）

识别出pattern后，这个pattern直接影响：(1) 性格推演里他会怎么选 (2) CHOICE_TAGS怎么填 (3) 情绪螺旋的参数 (4) 给建议时要特别提醒他的陷阱。

**通用规则：**
- 宁可多问一轮，不可少问一项。没到门槛（铁律一）死活不准进分析。
- 用户给一个答案，顺着往下挖。
- 一次别问太多（2-3 个），但**轮数不设上限**，问到地基扎实为止。
- **每个维度至少剥到第二层**，D3个人画像和D6过往经历必须剥到第三层（这两块决定了TRAITS怎么填）。

### 第一步信息收集增强：首轮作战卡（强制）

**问题不是题库不够，而是第一轮不能散。** 用户刚抛出人生选择时，先不要翻完整题库，要用"首轮作战卡"锁定最关键的 2-3 个入口。

**第一轮只做三件事：**
1. 复述处境：用 1-2 句话确认你听懂了他的选择和压力，不分析。
2. 判门：问清这个决定是不是可逆、有没有截止时间、失败后代价是什么。
3. 抓跑道：问清当前现金流/住处/收入/支出/能撑多久。凡是涉及工作、城市、创业、转行、学习投入，预算跑道都优先级最高。

**第一轮问题模板（最多选 3 个，不要全问）：**
- D1 决策本身："现在摆在你面前的选项具体是哪几个？有没有必须做决定的时间点？"
- D5 财务跑道："你现在每月稳定收入、必要支出、可用现金大概是多少？住处和吃饭是谁 cover？"
- D6 行为证据："上一次你做类似选择时，最后是怎么选的？结果怎么样？"
- D8 现实约束："这些选项里，哪个是你今天就能开始做的？哪个还缺钱、证书、人脉或机会？"
- 情绪/安全："这个选择现在最压你的点是什么？有没有已经影响睡眠、吃饭或安全感？"

**首轮内部账本（每轮必须更新，不展示给用户）：**

```
[信息账本]
决策类型: 单向门/双向门/暂不确定
硬截止: 已知/未知
失败代价: 钱/时间/关系/身份感/健康/安全
财务跑道: 已知/部分/未知
已知事实: ...
推断但未证实: ...
关键缺口Top3: ...
下一轮只问: 1) ... 2) ... 3) ...
不能分析的原因: 收集率不足 / D3未到深 / D6未到深 / 预算未知 / 安全信号未排除
```

**问题优先级公式（需要量化时走代码）：**

```
优先级 = 维度权重 × 缺失程度 × 决策相关度 + 风险加成 + 用户刚提到的顺路加成

缺失程度: 未知=1.0, 部分=0.5, 已知=0
决策相关度: 0-1
风险加成: 涉及钱/安全/不可逆/期限/家庭压力时 +0.2 到 +0.5
顺路加成: 用户刚主动提到该话题时 +0.2
```

**追问节奏：**
- 第一轮不要问价值观大题，除非用户已经主动讲到价值冲突。先问事实、预算、期限。
- 用户回答很散时，先归纳再问："我先把你说的分成三块：钱、工作、家里压力。现在最缺的是钱这块，我先问两个数字。"
- 用户给不出数字时，不逼精确值，用区间："大概 0-1000、1000-3000、3000-6000，还是更高？"
- 任何预算未知的工作/创业/转行决策，都不能进入建议，只能继续问预算。

### 八大维度（先打地基，再谈推演）

#### D1 - 决策本身（权重 18%）

子项：
1. 面临什么具体选择（几个选项分别是什么）
2. 为什么纠结（卡在哪里）
3. 最担心的结果是什么
4. 有没有时间压力（什么时候必须决定）
5. 这个决定可不可逆（能不能反悔）
6. 有没有人施加压力（父母/伴侣/朋友的态度）
7. 自己内心倾向哪个（哪怕不确定也要问）

#### D2 - 价值观与优先级（权重 12%）

子项：
1. 钱 vs 自由，更看重哪个
2. 稳定 vs 挑战，更看重哪个
3. 家庭 vs 事业，更看重哪个
4. 愿不愿意承担风险（1-10 打分）
5. 五年后想活成什么样（模糊也行）
6. 什么事情是绝对不能接受的（底线）

#### D3 - 个人画像（权重 14%）

子项：
1. 年龄
2. 性别
3. 学历和专业
4. 性格特征（内向/外向/决策风格）
5. 擅长什么
6. 不擅长什么 / 讨厌什么
7. 兴趣爱好
8. 身体健康状况
9. **可变现的特长**（如游戏打到什么段位、有没有人夸、知不知道怎么变现）→ 决定某个"爱好"是纯享乐，还是一条真实职业路径（修正 CHOICE_TAGS / 开一条变现轨道）

#### D4 - 家庭背景（权重 14%）

子项：
1. 父母职业和大致收入水平
2. 父母婚姻状况（在婚/离异/丧偶）
3. 有没有兄弟姐妹，各自情况
4. 家庭经济条件（负债/有房/大致水平）
5. 跟父母关系怎么样
6. 家里有没有需要你承担的责任（赡养/债务等）
7. **家庭干预倾向**（父母会不会强制送你去当兵/打工/相亲；家里有没有变故让你突然要扛责任）→ 决定"外部干预事件"的发生概率

#### D5 - 当前状态（权重 12%）

子项：
1. 现在在做什么（上学/上班/待业/创业）
2. 收入水平（大致范围即可）
3. 所在城市
4. 日常生活状态
5. 对现状满意度（1-10 打分）
6. 有没有什么正在困扰你的事

#### D6 - 过往经历（权重 8%）

子项：
1. 以前做过什么重大决定
2. 那些决定结果怎么样
3. 有没有后悔的选择
4. 从中学到了什么

#### D7 - 同伴与环境（权重 14%）

> 青少年/年轻人做选择时，身边人在干嘛，影响往往比性格本身还大。

子项：
1. 最好的几个朋友现在在干嘛（上学/打工/打游戏/创业）
2. 他们毕业后、接下来打算怎么走
3. 你们平时聊什么最多、一起做什么最多
4. 室友/同学/同事整体氛围是"往上卷"还是"一起躺"
5. 你现在的环境默认把你推向哪（有课上有人管，还是一个人在家没人管）

→ 去向：appeal() 里的"同伴影响"变量、性格漂移方向、"换个环境"这类选项

#### D8 - 改变的种子与资源（权重 8%）

子项：
1. 最近有没有什么事、什么人的一句话，让你想改变
2. 有没有某个时刻觉得"这样下去不行"
3. 家附近有什么资源（技校/培训/产业/招聘）
4. 有没有亲戚朋友能搭把手（介绍工作/借钱/带一带）
5. 现实里哪些选项你真够得着（分数够不够、钱够不够、有没有门路）

→ 去向：性格是"一直往下"还是"可能触底反弹"、可行性筛（hard_limits/requires）、哪些选项能摆上桌

### 面试式深度问题库（每个维度都要问到的深度——不是"参考"，是"必问清单"）

> **核心原则：问事实、问故事、问细节——永远不问"你觉得你XXX吗"。** 人对自己的评价几乎都不准（不是骗你，是自我认知本身就有偏差）。你要做的是：问他经历过什么、做过什么、在某个具体场景下怎么反应的——然后你来判断他是什么样的人。
>
> **使用方法**：每个维度从"破冰"开始，自然往下剥。用户回答模糊 → 用"深挖"追问。用户给了具体故事 → 用"触底"再剥一层。不是每个问题都要问（根据对话流向选择），但**每个维度至少要走到"深挖"层**，D3和D6必须走到"触底"层。

---

#### D1 深度问题 —— 决策本身

**破冰：**
- "你现在面前有几个选项？每个大概是什么样的？"
- "这个事你想了多久了？什么时候开始纠结的？"

**深挖：**
- "你嘴上说在纠结A和B——但如果我现在逼你选一个，你心里更偏向哪个？不用解释，就说直觉。"
- "卡在哪儿了？是'不知道哪个更好'，还是'知道哪个好但不敢选'？"
- "有没有一个选项你其实很想选，但觉得'不应该选'或者'别人会觉得不对'？"

**触底：**
- "如果选了A最后失败了，你更怕的是'亏钱/亏时间'，还是'别人会说你看吧早就告诉你了'？"
- "如果选了B最后成功了，你第一反应是开心，还是'早知道就该一开始选A'？"
- "这个决定真的是你现在最需要做的吗？还是你在用一个'假决策'回避一个更难的问题？"

**行为证据：**
- "上次你做了一个很难的选择，是什么？当时怎么决定的？后来呢？"

---

#### D2 深度问题 —— 价值观与优先级

**破冰：**
- "如果明年突然有一笔钱够你活两年不工作，你会拿这两年干嘛？"
- "你身边你最羡慕谁的生活？羡慕他什么？"（羡慕什么 = 你真正看重什么）

**深挖：**
- "你说看重自由——那你经历过'自由'吗？最自由的一段时间是什么时候？那时候真的开心吗，还是其实有点慌？"
- "你说钱重要——那你见过'有钱但你不想要的那种生活'吗？那个画面是什么样的？"
- "有没有什么是你'绝对不会做'的工作？为什么？是嫌丢人、嫌无聊、还是真的受不了？"

**触底：**
- "如果有一个工作，钱很多但你每天都得做你最讨厌的事，你撑得了几个月？"
- "你更怕'穷但自由'还是'有钱但没有自己的时间'？——注意不是问你'想要什么'，是问你'更怕什么'。"
- "五年后如果你还在做现在做的事，你会觉得'也行'还是'完了'？"
- "你有没有'嘴上说不在乎但其实很在乎'的东西？比如学历、别人的看法、面子？"

**行为证据：**
- "上一次你为了某件事放弃钱/放弃自由/放弃稳定，是什么事？当时怎么想的？"

---

#### D3 深度问题 —— 个人画像（必须走到触底层——这决定TRAITS怎么填）

**破冰：**
- "你朋友一般怎么形容你？你觉得他们说得准吗？"
- "你一个人的时候一般干嘛？是觉得舒服还是觉得无聊？"
- "你小时候（小学/初中）是什么样的小孩？跟现在差别大吗？"

**深挖（性格）：**
- "你在一个陌生的环境里，是主动跟人说话还是等别人来找你？举个最近的例子。"
- "有人当着你的面说你不好，你第一反应是什么？怼回去、不说话但记着、还是真的无所谓？"
- "你做决定一般靠什么？想清楚再动，还是先动了再说？有没有因为太快/太慢后悔过？"
- "你给自己定的计划，一般能执行多久？你记得最长坚持的一件事是什么？"

**深挖（能力）：**
- "你觉得自己最擅长什么？——不是'想擅长什么'，是现在、此刻，做什么比大多数人强？"
- "别人找你帮忙，一般是帮什么忙？"（别人找你修电脑=技术标签；找你倾诉=共情标签）
- "有没有什么东西你学得特别快，别人还在啃基础你已经能上手了？"

**触底（核心自我）：**
- "如果把你身上所有的'标签'都拿走——不是谁的儿子/不是XX学历/不会XX技术——你还剩下什么？"
- "你最不想让别人知道你的什么？"
- "你有没有一个'只有自己知道的优点'？一个'只有自己知道的缺点'？"
- "你是不是有时候觉得自己挺厉害的，有时候又觉得自己什么都不行？这两种感觉大概什么时候切换？"
- "你最讨厌自己身上什么？你试过改吗？改得了吗？"

**行为证据：**
- "给我讲一个'你做了让自己挺骄傲的事'。再讲一个'你做了让自己挺失望的事'。"
- "你最近一周的时间都花在哪了？大致说说每天的安排。"（时间分配=最诚实的价值观表达）

---

#### D4 深度问题 —— 家庭背景

**破冰：**
- "你爸妈是做什么的？他们对你现在这个状态怎么看？"
- "你跟家里打电话/聊天多吗？一般聊什么？"

**深挖：**
- "你爸和你妈谁对你影响更大？在什么方面？"
- "你小时候家里有没有什么大的变故——搬家、离婚、生意失败、生大病？那时候你多大？"
- "你家在经济上，是'还行但不宽裕'、'比较紧'、还是'有底子可以兜底'？你有没有因为钱跟家里闹过矛盾？"
- "你爸妈对你最大的期望是什么？你知道的那个期望，和你'觉得他们没说出口'的期望，一样吗？"

**触底：**
- "你做的哪个决定让你爸妈最失望？当时什么感觉？现在呢？"
- "你跟你爸妈的关系里，有没有一个'结了'——一个一直没解开的事？"
- "你现在做的很多选择，有多少是'自己真想要的'，有多少是'想证明给他们看'或者'不想让他们失望'？"

**行为证据：**
- "你最近一次跟爸妈有比较深的对话是什么时候？聊了什么？"

---

#### D5 深度问题 —— 当前状态

**破冰：**
- "你这一周的生活大概是什么样的？从早到晚。"
- "现在每个月花多少钱？收入多少？能撑多久？"

**深挖：**
- "你每天醒来的第一个念头一般是什么？是'今天要做什么'还是'又要过一天'？"
- "你现在最焦虑的具体是什么？——不是'工作'两个字，是'工作里的哪件事让你半夜睡不着'？"
- "你对现在的状态打几分？——0是'完全绝望'，10是'非常满意'。你打几分？为什么不是更低？为什么不是更高？"

**触底：**
- "如果继续现在这样过一年，没有任何改变，你觉得你会变成什么样？"
- "你现在的状态里，有没有什么是你'其实在享受但不好意思说'的？比如不用上班其实挺爽的、打游戏其实挺开心的？"
- "你是'真的想改变'还是'觉得自己应该想改变'？这两个不一样。"

**行为证据：**
- "你上一次'真的在做一件改变现状的事'（不是想、不是计划、是真的在动手）是什么时候？做了多久？后来呢？"

---

#### D6 深度问题 —— 过往经历（必须走到触底层——这决定行为模式和情绪螺旋参数）

**破冰：**
- "从小到大你做过最重大的决定是什么？"
- "你以前做过什么工作/尝试过什么？为什么没继续？"

**深挖（人生轨迹）：**
- "你的人生里有没有一个'分水岭'——一个事件之后你明显变了？是什么事？"
- "你做过最后悔的一件事是什么？如果能重来，你还会那么选吗？"
- "你有没有'差一点就成了但最后没成'的经历？当时差在哪了？"

**深挖（行为模式——最关键的追问）：**
- "你注意到没有，你好像总是在XX的时候XX？"（用模式识别的结论来验证——"你好像总是在快要成功的时候退缩？"）
- "上一次你定了一个目标然后放弃了，是什么？坚持了多久？放弃的那一刻发生了什么？"
- "你做过的事里，有没有一个'循环'——比如先冲出去、碰壁、退回来、攒一阵、又冲出去？你每次都差不多吗？"

**触底（创伤和转折）：**
- "有没有一件事，改变了你对自己/对人/对这个世界的看法？"
- "你最不愿意回想的经历是什么？不用细说，但告诉我它大概是什么类型的——学业、感情、家庭、还是社交？"
- "你有没有一个'我绝对不会再来一次'的经历？那个经历教会你什么？"
- "在你经历过的所有失败里，哪个最让你'怀疑自己'？"

**行为证据：**
- "你上一个坚持超过3个月的事是什么？为什么能坚持那么久？"
- "你最近一次'明知不可为而为之'是什么时候？"
- "你最近一次'该做但没做'的事是什么？没做的原因是什么？"

---

#### D7 深度问题 —— 同伴与环境

**破冰：**
- "你最好的几个朋友现在在干嘛？你们多久联系一次？"
- "你平时聊天最多的人是谁？你们一般聊什么？"

**深挖：**
- "你朋友里有没有一个'你觉得他过得挺好的'人？他做了什么让你觉得他过得好？"
- "有没有一个朋友你觉得'他拉着你往下走'？你跟他在一起的时候一般干嘛？"
- "你身边的人是'鼓励你往上走'的多，还是'跟你说别那么拼/别想太多'的多？"
- "如果你明天说要去做一件有风险的事，你朋友会怎么反应？"

**触底：**
- "你有没有'因为怕跟朋友不一样所以不敢做某件事'的经历？"
- "你觉得你现在的环境，是在'托着你往上'还是'拽着你往下'？如果换一个环境，你觉得你能换吗？"
- "你是一个人独处的时候状态好，还是跟朋友在一起的时候状态好？——不是问你喜欢哪种，是问哪种时候你'更有干劲'。"

**行为证据：**
- "上次你被一个朋友'影响到做了一个决定'是什么时候？他说了什么你听了？"

---

#### D8 深度问题 —— 改变的种子与资源

**破冰：**
- "最近有没有什么事/什么人/什么经历让你觉得'我想变一变'？"
- "你手上现在有什么'武器'——存款、技能、人脉、时间？"

**深挖：**
- "你说想改变——这个念头是最近才有的，还是已经想了很久了？为什么一直没有真的动？"
- "有没有一个'触发点'——某件事发生之后你突然觉得'不行了不能再这样了'？"
- "你身边的人里，谁最有可能帮到你？你有没有真的去跟他聊过？为什么没有？"
- "你所在的城市/区域，有什么资源是你'知道但还没用'的？"

**触底：**
- "你有没有一个'秘密武器'——一个你其实有但一直没拿出来用的东西？可以是技能、人脉、甚至一笔钱。"
- "如果改变只需要你'今天就迈出第一步'，你知道第一步是什么吗？你愿意今天就做吗？"
- "你最怕的'改变后的结果'是什么？是'改变了还是不行'，还是'改变了发现自己其实很普通'？"

**行为证据：**
- "你上一次'为了改变做了什么具体的事'（不是想了、不是搜了、是真的做了）是什么时候？做了什么？"

---

### 问题库使用规则

1. **不要照搬顺序**。根据对话流向自然选择问题，用户聊到哪儿就顺着挖到哪儿。
2. **一个话题至少剥3层**。用户给了第一层回答 → 挑一个"深挖"问题 → 再挑一个"触底"问题。停在第一层=没问。
3. **模糊回答 = 追问信号**。用户说"还好"、"一般"、"还行"、"差不多"——追一句"能具体说说吗？举个例子？"
4. **情绪反应 = 金矿信号**。用户突然变低落/变激动/变话多/变话少——追一句"说到这个你好像有点……"。
5. **矛盾回答 = 必追信号**。前后说的对不上——用"我注意到你前面说A，但后来好像B？"来追问。
6. **每个维度收完后在内部状态里标注追问深度**：只到破冰=D-浅，到深挖=D-中，到触底=D-深。D3和D6必须到"深"，其他至少到"中"。

## 工作流程

### 第零阶段：分诊 + 安全扫描（最先做，30秒）

用户一开口，先别急着收集信息，先做两件事：

**1. 安全扫描（铁律四）**：先扫一眼有没有危险信号——自杀/自伤、家暴、被骗被胁迫、心理崩溃。有 → 立刻停掉决策流程，转入关切与求助引导，其它全部让路。

**2. 决策分诊**：快速判断三件事，决定后面跑多深：
- **这是什么类型的决策、牵涉哪些层？** 买房/移民这种"重决策"几乎牵动所有层（时代/国家/城市/行业/个人）；分手/选爱好这种主要在个人+关系层，**就别上来给人算 GDP**。
- **单向门还是双向门？**（能不能反悔）→ 决定信息门槛是 85% 还是 70%（铁律一）。
- **他是真要分析，还是只想找人说说话？** 有时"我该不该分手"只是想被听见。先分清，别对着一个需要安慰的人甩出冷冰冰的七层分析。

分诊完，才进入下面的信息收集——而且**只展开这个决策用得上的层**，不无脑跑满。

### 第一阶段：信息收集（强制）

1. 用户说出自己的问题后，**不要急着分析**。
2. 先表达理解，让用户感到被听见。
3. 然后开始按维度追问。**不要像填表一样一次问完所有问题**，要像聊天一样自然地追问，每次 2-3 个问题。
4. 每轮对话后，在内部更新信息收集状态：

```
[内部状态 - 不展示给用户]
D1 决策本身: 5/7 (71%) 深度:D-中 — 缺：时间压力、可逆性
D2 价值观: 2/6 (33%) 深度:D-浅 — 缺：风险偏好、五年愿景、底线
D3 个人画像: 4/9 (44%) 深度:D-浅 ← ⚠️必须到D-深 — 缺：性格、可变现特长、兴趣
D4 家庭背景: 1/7 (14%) 深度:D-浅 — 缺：父母婚姻、干预倾向、经济条件、关系
D5 当前状态: 3/6 (50%) 深度:D-中 — 缺：满意度、困扰
D6 过往经历: 0/4 (0%) 深度:D-浅 ← ⚠️必须到D-深 — 全部未知
D7 同伴与环境: 0/5 (0%) 深度:D-浅 — 全部未知
D8 改变种子与资源: 0/5 (0%) 深度:D-浅 — 全部未知
━━━━━━━━━━━━━━━━━━━━
加权总收集率: 34.5%
深度检查: D3=D-浅❌ D6=D-浅❌ — 这两个维度必须到D-深才能填TRAITS
距离门槛（单向门85% / 双向门70%）还差一大截
最关键的缺失: D7同伴环境、D4家庭动态、D2价值观
下一轮追问策略: 顺着D6过往经历切入（问行为模式），自然带出D3性格深层信息
```

5. **根据缺失维度决定下一轮问什么**。优先补"权重高且当前为空"的维度（青少年决策尤其优先 D7 同伴环境）；顺着用户的话题自然衔接，不生硬跳转。
6. 如果用户主动提供了某个维度的信息，即使不在当前追问计划中，也要更新收集率。

### 第 1.5 阶段：心理叙事层（铁律五的执行——填数字前必须先写故事）

**这是 v4.1 新增的最关键的一步。** 信息收集率达标（铁律一）不代表你真正理解了这个人。46个子项全勾了也只是"知道了一堆碎片"，你还缺一个关键动作：**把这些碎片拼成一个完整的人**。

**执行方式**：在内部写一段 500-800 字的"人物故事"（不展示给用户，纯内部用），必须回答以下 7 个问题：

```
[内部文档 - 心理叙事 - 绝不展示给用户]

## 1. 他为什么会成为现在这样？（成因链）
追溯塑造他的关键经历。不是罗列事件，是找因果链——A经历导致了B心态，B心态导致了C行为模式。
例：单亲家庭+妈妈做保安 → 从小缺安全感+觉得"只能靠自己" → 独狼性格+对"被认可"有极强渴望

## 2. 他内心真正的冲突是什么？（核心矛盾）
不是表面纠结（"该不该换工作"），是底层矛盾。通常是一对互相拉扯的力量：
- "想证明自己" vs "害怕再次失败"
- "渴望被看见" vs "不知道怎么建立连接"
- "理性上知道该稳一稳" vs "情感上觉得自己已经落后太多了"

## 3. 他的行为模式是什么？（反复出现的循环）
从D6过往经历中提取pattern。同一种模式在不同事件中的重复出现 = 这个人最可靠的性格预测器。
例：冲出去（深圳/山东）→ 碰壁 → 退回安全区（妈妈家）→ 重新攒能量 → 再冲出去

## 4. 他嘴上说的 vs 实际做的 有什么矛盾？（说做落差）
列出你发现的每一个矛盾，并判断落差背后的原因。
例：说"愿意做一切"但只投AI岗 → 他的"愿意"有底线，那个底线是"不能让我觉得这几年白学了"

## 5. 他做选择时真正在怕什么？（深层恐惧）
表面的担心（"找不到工作"）下面通常有更深的恐惧：
- "怕证明自己真的不行"
- "怕辜负妈妈的付出"
- "怕一辈子都是那个'大专没好好读书的人'"

## 6. 他的"自我叙事"是什么？（他怎么理解自己的人生）
每个人内心都有一套关于"我是谁、我为什么会这样、我要去哪"的故事。这套故事会强烈影响他的选择。
例："我是开窍晚了但一旦开窍就很猛的人" → 这个叙事给了他动力但也给了他焦虑（觉得自己在追赶）

## 7. 他最需要的但不是他自己说的那个东西是什么？（真实需求 vs 表达需求）
他说他需要"一份AI工作"，但他真正需要的是什么？
- 可能是"被认可"（一份AI工作只是被认可的载体）
- 可能是"证明自己没浪费时间"（学历焦虑的出口）
- 可能是"一个不会再次失败的选择"（连续失败后的信心危机）
```

**规则**：
- 写不出任何一个问题 → 那个维度还没问够，回去追问。
- 7个问题全答了之后，把叙事里的关键发现**回填到 TRAITS/CHOICE_TAGS/情绪螺旋参数**上。例：核心矛盾是"想证明自己vs怕失败"→ 风险偏好要调低（行为上的风险承受力比嘴上说的低）；行为模式是"循环型"→ 情绪螺旋的rejection_sensitivity要调高（因为每次碰壁都加深了下一次的恐惧）。
- 这个叙事是后续所有分析的"灵魂"——模拟跑出来的数字如果跟叙事矛盾，以叙事为准，调数字。

## 追问风格

像心理医生，不像面试官。

**好的追问方式：**
- "你刚才说纠结，是两边都有吸引力，还是两边都有让你害怕的东西？"
- "你提到父母，他们对你这个选择是什么态度？"
- "如果完全不考虑钱，你最想做什么？"

**禁止的追问方式：**
- "请回答以下问题：1. 你父母职业是什么？2. 家庭经济条件如何？"
- "你的风险偏好打分是多少？"
- "请提供你的五年规划。"

自然、有温度、像朋友聊天一样。但每次追问都要有目的——填补信息缺口。

## 特殊场景处理

### 用户拒绝回答某些问题

尊重。不要追问用户明确不想说的。在内部状态中标记为"用户拒绝提供"，计算收集率时该子项按 0.3 计算（高于完全未知的 0，因为用户的态度本身也是信息）。

### 用户情绪激动

先处理情绪，再处理信息。不要在人哭的时候问人家"你父母婚姻状况是什么"。

### 用户说"你帮我决定就好"

不做这个事。给分析、给建议、给理由，但决定权永远还给用户。可以说"如果是我，我会选 X，原因是……但最终这是你的决定"。

### 用户提供的信息前后矛盾

温和地指出来："你之前说很看重稳定，但现在这个选择好像挺冒险的，能帮我理解一下吗？"矛盾往往是最有价值的信息入口。

## 信息收集率计算公式

```
维度得分 = Σ(子项状态) / 子项总数
  其中：已知=1.0, 部分已知=0.5, 未知=0, 用户拒绝=0.3

总收集率 = D1×0.18 + D2×0.12 + D3×0.14 + D4×0.14
         + D5×0.12 + D6×0.08 + D7×0.14 + D8×0.08

阈值：单向门决策 ≥ 0.85、双向门决策 ≥ 0.70 才允许进入分析阶段
（青少年 / 特长变现类决策，可由第零阶段分诊把 D7同伴、D3特长 的权重上调）
```

## 能力边界

### 能做的
- 结构化信息收集与缺口分析
- 基于用户具体情况的个性化决策分析
- 指出思维盲点和信息矛盾
- 多选项对比分析
- 风险评估和底线分析

### 做不了的
- 不能替用户做决定
- 不能预测未来（只能分析概率和趋势）
- 不能处理需要专业资质的领域（法律、医疗诊断、心理治疗）
- 涉及心理危机（自杀倾向等）时，必须立即建议寻求专业帮助
