# 问卷模式（一次性收集，代替多轮追问的快速通道）

聊天式追问（information-intake.md）是默认模式，但它慢——每轮 2-3 题，达标要聊很多轮。当用户更愿意"一次把问题全给我，我慢慢填"时，切换到问卷模式：把下面的问卷整理后**一次性发给用户**，用户填完一次回收 60-80% 的信息量，剩下的缺口再用 2-3 轮定向追问补齐。

## 什么时候用问卷模式

满足任一条件就主动提出（提出 ≠ 强制，用户选）：

1. 用户明确说"问卷/一次问完/把问题都发我/别一个个问"。
2. 聊天式追问进行了 2 轮，信息增速明显慢（用户回答简短、被动）。
3. 用户是打字型选手：回复长、条理清楚、喜欢一次说完。
4. 决策有硬截止且时间紧，没有奢侈的多轮空间。

提出话术示例："这个决定要做好，我需要比较全面地了解你的情况。两种方式：我们像现在这样聊（我每次问两三个），或者我把问题打包成一份问卷发你，你一次填完（答不上的写'不知道'，不想答的写'跳过'）。哪种舒服？"

## 问卷使用规则（重要）

1. **发卷前先做第零阶段**：安全扫描 + 判门 + 判断决策类型。问卷是第一阶段的工具，不能替代分诊。
2. **按决策类型裁剪**：核心卷（A卷）全发；附加卷（B卷）只发对应决策类型那一节。总题数控制在 35 题以内，太长用户会摆烂。
3. **明确告知规则**："每题都可以写'不知道'或'跳过'，跳过不影响我们继续，但会影响我分析的把握度。"（内部按拒绝=0.3、未知=0 计分。）
4. **回收后逐题映射打分**：按下方"题号→维度"映射表逐题标记 已知1.0/部分0.5/拒绝0.3/未知0，然后**必须运行 `scripts/intake_score.py`** 算收集率——不许心算。
5. **问卷 ≠ 完事**。问卷天花板是"D-中"深度：它收的是事实，收不到"触底层"的东西（说做落差、深层恐惧、行为模式循环）。回收后必须：
   - 对 D3/D6 做 2-3 轮**定向触底追问**（从问卷答案里挑最有信息量的线头往下剥，用 information-intake.md 的触底题）；
   - 完成心理叙事（1.5 阶段）才能进推演。**跳过这一步 = 问卷模式失效，禁止。**
6. **矛盾检测**：问卷答案内部互相矛盾的（如 Q7 说风险都敢冒、Q26 说上次机会退了），全部记下来，追问阶段优先追矛盾。

## A卷 · 核心问卷（所有决策类型都发）

> 开头模板：以下问题帮我全面了解你的情况，才能给出对你真正有用的分析（而不是网上那种通用建议）。**每题答不上写"不知道"，不想答写"跳过"**。写事实和例子，不用修饰。

**【这个决定本身】**
1. 你现在面临的选项具体是哪几个？每个选项一句话描述。
2. 有没有必须做决定的最后期限？是什么时候、为什么是那个时间？
3. 这个决定如果做错了，能反悔吗？反悔的代价是什么？
4. 你最担心的最坏结果是什么？
5. 有没有人在推你选某一边（父母/伴侣/朋友）？他们各自希望你怎么选？
6. 如果现在逼你立刻选一个，你的直觉选哪个？（不用解释理由）
7. 这个事你纠结多久了？从什么时候开始的？

**【钱和现状】**
8. 你现在每月稳定收入多少？来源是什么？
9. 每月必要支出多少（房租/吃饭/交通/还款等，分项列）？还有哪些能压缩的支出？
10. 现在手上可用的现金和能快速变现的东西加起来大概多少？
11. 近期有没有大额支出要发生（押金/学费/设备/医疗）？
12. 家里能不能支持你？能支持多少、能撑多久、他们的支持稳不稳？
13. 你现在每天的生活大概什么样（在上班/上学/待业/其他）？给现状打个分：0=完全绝望，10=非常满意。打几分？为什么不是更低/更高？

**【你这个人】**
14. 年龄、学历/专业、所在城市。
15. 你现在最拿得出手的技能/证书/经验是什么？（是"现在就能用的"，不是"想学的"）
16. 别人一般找你帮什么忙？朋友怎么形容你？
17. 你做决定偏向想清楚再动，还是先动了再说？举一个最近的例子。
18. 你给自己定的计划一般能坚持多久？你坚持过最久的一件事是什么、坚持了多久？
19. 有没有什么爱好/特长厉害到"有人夸过/能变现"的程度？（比如游戏段位、写作、做视频、修东西）
20. 身体状况有没有需要考虑进决策的（慢性病/体力限制/心理状态）？

**【家庭】**
21. 父母做什么的？家里经济上是"能兜底"、"过得去"还是"比较紧/有负债"？
22. 你有没有需要承担的家庭责任（赡养/弟妹/债务）？
23. 父母对你现在的状态和这个决定是什么态度？他们会不会直接干预（强制安排工作/相亲/要求回家）？

**【过去】**
24. 从小到大你自己做过的最大的决定是什么？结果怎么样？
25. 有没有一次"冲出去→碰壁→退回来"的经历？具体说说。
26. 上一次遇到"有机会但有风险"的事，你是上了还是退了？后来怎么想？
27. 你最后悔的一个选择是什么？如果重来会怎么选？

**【身边人】**
28. 你最好的3个朋友现在分别在干嘛？你们多久联系一次？
29. 你身边的人整体是在"往上卷"还是"一起躺"？他们知道你在纠结这个事吗、怎么说？

**【改变的资源】**
30. 最近有没有什么事/什么人让你觉得"必须变一变了"？是什么？
31. 你身边有没有能搭把手的人（介绍工作/借钱/带路）？你真的去找过他们吗？
32. 这些选项里，哪个是你今天就能迈出第一步的？第一步是什么？

## B卷 · 分类型附加卷（只发对应类型）

**B1 职业/跳槽/转行**
1. 现在这份工作（或上一份）具体做什么？干了多久？月薪多少？
2. 想去的方向具体是什么岗位？你投过几份？拿到几个面试/offer？
3. 那个方向的人的真实日常你了解吗？从哪了解的（认识真人/网上看的）？
4. 你的技能离目标岗位的要求差什么？这个差距要多久能补上？
5. 如果转行失败，你能接受回到现在这类工作吗？

**B2 城市/搬家**
1. 目标城市去过吗？待过最长多久？在那边有认识的人吗？
2. 那边的房租/生活成本你查过吗？大概多少？
3. 现在这个城市有什么走不掉的牵挂（人/事/资产）？
4. 去那边的第一份收入怎么解决？已经有着落还是过去再找？

**B3 创业/做自己的事**
1. 具体做什么？给谁解决什么问题？现在有没有人愿意为它付钱（哪怕一个人）？
2. 启动要多少钱？这钱从哪来？亏光了影响什么？
3. 你全职投入的话，最长能撑几个月不赚钱？
4. 有没有能一起干的人？还是纯单干？
5. 这个事最小成本的试法是什么？为什么不先试？

**B4 备考/读书/学习投入**
1. 考什么/学什么？为什么是它？考上/学成之后的路径你查证过吗？
2. 准备周期多长？这期间收入怎么办？
3. 你以前有没有长周期备考/自学的经历？结果如何？
4. 如果考不上/学完没用上，这段时间的代价你怎么看？

**B5 感情/婚姻/家庭**
1. 这段关系多久了？让你纠结的具体是什么事（不是"感觉"，是事）？
2. 这个问题你们正面谈过吗？对方怎么说？
3. 你身边最了解你们的人怎么看？
4. 如果维持现状一年不变，你觉得会怎样？
5. 这个决定涉及钱/房子/孩子吗？具体情况？

**B6 大额消费/投资（买房/买车/大件）**
1. 具体买什么？总价多少？首付/月供怎么构成？
2. 这笔钱占你总积蓄的比例？付完之后手上还剩多少活钱？
3. 不买的话，这笔钱你会怎么用？
4. 有没有人在催你买（家人/销售/同龄人压力）？

## 题号 → 维度映射表（回收打分用）

| 维度 | A卷题号 | 子项对应 |
|---|---|---|
| D1 决策本身 | 1-7 | 1→选项 2→时间压力 3→可逆性 4→最坏结果 5→他人压力 6→内心倾向 7→纠结起点 |
| D2 价值观 | 4,6,13,26,27 + 追问补 | 问卷只能覆盖一部分，风险偏好用26反推，底线/五年愿景靠追问 |
| D3 个人画像 | 14-20 | 14→基本信息 15→擅长 16→他评 17→决策风格 18→自律 19→可变现特长 20→健康 |
| D4 家庭背景 | 21-23 | 21→职业与经济 22→责任 23→态度与干预倾向 |
| D5 当前状态 | 8-13 | 8-12→收入支出现金 13→现状与满意度 |
| D6 过往经历 | 24-27 | 24→重大决定 25→行为循环 26→风险行为证据 27→后悔 |
| D7 同伴环境 | 28-29 | 28→朋友现状 29→环境氛围 |
| D8 改变种子 | 30-32 | 30→触发点 31→资源人脉 32→够得着的第一步 |
| B卷各节 | 对应决策类型 | 主要补 D1 的选项事实 + D5 现状细节 + 可行性硬条件（hard_limits） |

**打分纪律**：写了具体事实=1.0；写得含糊（"还行""一般"）=0.5 且列入追问清单；写"跳过"=0.3；写"不知道"或空着=0。逐题标完**必须跑 `intake_score.py`**，凭证里 `允许分析=是` 才能往下走。

## 回收后的标准流程

```
用户交卷
  → 逐题映射打分（照上表）
  → 跑 intake_score.py（拿凭证）
  → 未达标：从缺口最大的维度挑 2-3 题定向追问（聊天式），补完再跑一次
  → 达标：对 D3/D6 做触底追问（2-3轮，问卷替代不了这层）
  → 写心理叙事（1.5阶段，7问全答）
  → 才允许进预算/推演
```
