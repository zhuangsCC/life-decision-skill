# 分析输出与执行路线图

本文件用于最终建议、隐藏路径发现、最小可行改变、风险提示、止损线、复盘点和执行路线图。只有在达到信息门槛、完成预算/外部环境、完成推演后才能读。

## 执行凭证（报告第 0 节，强制，缺了整份报告无效）

最终报告的**最前面**必须有一个"执行凭证"块，**原样粘贴**三个脚本各自打印的 `[凭证]` 行：

```
[执行凭证]
[凭证] intake ts=... score=...% door=... threshold=... D3深=是 D6深=是 允许分析=是
[凭证] budget ts=... 正常档跑道=...个月 灯=...        ← 或 mcts 凭证里的 budget 跳过(原因:...)
[凭证] mcts ts=... iters=... sims=... months=... seed=... gate=(...)
```

自检规则（输出报告前逐条核对）：
1. 三行凭证是不是都来自**本次对话真实运行**的脚本输出？手写的、上次会话残留的、`--example` 的都不算。
2. intake 凭证是不是 `允许分析=是`？不是就回第一阶段。
3. mcts 凭证的 gate 字段是不是显示了 intake/budget 的来源？出现 `FORCED` 或 `example模式` 字样 = 无效。
4. 任何一条不满足：不许输出建议，回去补对应步骤。用户看到凭证块，就能自己监督流程有没有被偷工减料——这正是它存在的目的。

### 第四阶段：分析与建议（信息达标[门槛见铁律一] + 外部环境采集完成 + 推演完成）

达到对应门槛后，才允许输出分析。分析结构：

1. **决策全景** — 用一段话概括你理解的用户完整处境，让用户确认你理解对了。
2. **可行性确认** — 先说清哪些选项被硬条件（钱/资格/签证）筛掉了，只在做得到的选项里分析。
3. **选项分析** — 每个选项从短期收益、长期影响、风险下限、与价值观匹配度，以及二阶/三阶连锁后果（"然后呢"问三层）来分析。
4. **最优 vs 现实** — 把 MCTS 的"该怎么选"和性格推演的"他大概会怎么选"并排摆出，差距就是要点破的"性格税"。
5. **小步试错选项** — 永远主动提一句："能不能先小成本试一下、或先别急着定，而不是一把梭哈？"
6. **关键洞察 + 偏差提醒** — 指出盲点、矛盾、认知偏差（损失厌恶/沉没成本/现状偏差/从众）。研究表明人普遍低估"关系"、高估"稳定"，可据此反问，但不替用户改价值观。
7. **建议** — 给出明确建议，不要和稀泥。说清楚"我建议选 X，因为……"。
8. **风险提示 + 黑天鹅压测 + 止损线** — 常规最坏情况怎么应对；再单独问"万一黑天鹅（疫情/政策突变）来了哪个选项扛得住"；并和用户定好"复盘点"（如3个月后回看）和"止损线"（出现什么信号就撤）。
9. **隐藏路径发现（强制，不可跳过）** — 模拟只跑了"摆在桌上的选项"，但用户可能有**没想到的路**。必须主动搜索至少2-3条"隐藏路径"，逻辑如下：
   - **资产盘点法**：用户手上有什么"资产"（技能/设备/人脉/经历/证书），这些资产能组合出什么不在现有选项里的路径？（例：有4070ti显卡→可以做GPU算力出租/本地模型推理服务；有AI开发能力→可以做AI教学视频/付费社群）
   - **行业对标法**：同行业、同背景的人走过什么路？联网搜索"XX背景的人怎么赚钱/怎么转型"。
   - **组合法**：用户的A能力 + B资源，能不能组合出一条新路？（例：懂AI + 懂会计 = AI财务自动化工具）
   
   找到的隐藏路径如果可行（满足 hard_limits），加进 tracks 重跑模拟，和原选项对比。
10. **最小可行改变分析（走代码，强制输出）** — 模拟跑完后，找出"改哪个单一变量、花最小代价，能让结论翻转或显著提升"：

```python
# 最小可行改变分析
# 对每个核心参数做 +10 的反事实测试，看哪个变量对结果影响最大
params_baseline = {"能力弹药库":60, "赛道景气度":72, "方向清晰度":73, "安全垫厚度":48}
results = {}
for param, baseline in params_baseline.items():
    # 模拟: 如果这个参数 +10 会怎样
    boosted = dict(params_baseline)
    boosted[param] = min(100, baseline + 10)
    # 这里用简化版MCTS或直接用已有结果做敏感性分析
    results[param] = f"从{baseline}→{boosted[param]}: 预期影响待模拟"

# 输出"杠杆点"
print("\n[最小可行改变]")
print("哪个变量提升10分，对结果影响最大？")
for param, info in sorted(results.items(), key=lambda x: x[1], reverse=True):
    print(f"  {param}: {info}")
print("\n→ 你的杠杆点是XXX：花最小代价提升它，整体结果改善最大")
print("→ 具体行动：[根据杠杆点给出1-2个最小行动]")
```

**杠杆点常见模式**：
- 安全垫低 → 杠杆行动：先找个收入来源（哪怕很少），稳住心态
- 能力弹药库低 → 杠杆行动：做一个能展示的作品，把"能力"变成"证据"
- 方向清晰度低 → 杠杆行动：小成本试错（花1-2周试一条路，不行就换）
- 赛道景气度低 → 杠杆行动：换赛道（不在衰退行业死磕）

**⚠️ 量化分析强制走代码**

分析阶段涉及的所有数字必须通过 Python 代码执行，包括但不限于：

- **收入/成本对比**：写代码算出各选项的 N 年财务影响（含通胀、机会成本）
- **风险量化**：用代码计算各选项的风险评分（基于用户提供的信息加权打分）
- **期望值分析**：用代码计算各选项的期望收益 = Σ(概率 × 收益)
- **价值观匹配度**：用代码量化各选项与用户价值观的匹配程度
- **时间成本**：用代码计算各选项的时间投入和回报周期

示例执行方式：
```python
# 用户面临跳槽决策，计算两个选项的5年财务影响
option_a = {
    "current_salary": 18000,
    "annual_raise": 0.08,
    "stability": 0.9,
}
option_b = {
    "current_salary": 30000,
    "annual_raise": 0.15,
    "stability": 0.5,  # 创业公司风险
}

for name, opt in [("A-留原公司", option_a), ("B-去创业", option_b)]:
    total = sum(opt["current_salary"] * (1 + opt["annual_raise"])**y for y in range(5))
    expected = total * opt["stability"]
    print(f"{name}: 5年总收益={total/10000:.0f}万, 风险调整期望={expected/10000:.0f}万")
```

把代码输出结果直接引用到分析中，不要自己"估算"数字。

### 第五阶段：执行路线图（模拟完了→明天该干嘛）

**模拟告诉你"该走哪条路"，执行路线图告诉你"这条路第一步迈左脚还是右脚"。** 没有这一步，前面所有分析都是空中楼阁。

**执行路线图必须根据模拟结果定制**，但遵循以下通用结构：

#### 阶段一：活下来（第1-2周）

解决最紧迫的生存问题。根据财务倒计时的结果决定紧迫度：
- **跑道 < 2个月**：本周就开始找工作。不是"想清楚再找"，是边找边想。目标：2周内拿到至少一个offer。
- **跑道 2-6个月**：可以花1周想清楚找什么类型的工作，但第2周必须开始投。
- **跑道 > 6个月**：可以从容选择，但仍建议1个月内有一份收入来源。

**找什么工作**（根据用户画像定制，不是泛泛说"找个基础工作"）：
- 列出用户**已有的、能直接用的**证书/技能/背景（如：会计大专+Office二级+AI能力）
- 搜索这些组合能匹配的**具体岗位类型**（如：财务软件实施/代账公司助理/ERP技术支持）
- 给出**判断标准**：这个工作适不适合 = 下班后还有没有精力做副业（核心指标不是工资高低，是"时间精力余量"）
- 给出**渠道建议**：根据用户城市推荐具体招聘平台和搜索关键词

#### 阶段二：建弹药（第1-3个月）

生存稳住后，开始同步建"能拿出手的东西"：
- **第1个月**：确定一个具体项目方向（从模拟结果里的"隐藏路径"和"杠杆点"中选），花2-4周做出MVP。MVP的标准不是"完美"，是"能让别人看懂你在做什么"。
- **第2个月**：把MVP公开出去（GitHub/小红书/B站/行业社群），开始积累"被看见"的概率。同步开始发内容（做项目的过程就是内容）。
- **第3个月**：根据公开后的反馈决定——有正反馈就加码，没有就调整方向。不要死磕一个没反馈的项目超过6周。

**每个项目方向给出具体的第一步**：
- 不是"做AI+会计工具" → 而是"找一个你认识的做会计的人，问他工作中最烦的重复劳动是什么，把这个做成自动化"
- 不是"发内容建品牌" → 而是"把你改造飞书bot的过程录一个5分钟视频，标题写'大专会计自学AI做了个销售机器人'"

#### 阶段三：转折点（第3-6个月）

到这个阶段应该有一些信号了。根据信号决定加速还是转向：
- **加速信号**：有人主动找你做项目/内容有稳定增长/有人付费了 → 加大投入，考虑减少基础工作的时间
- **停滞信号**：3个月没正反馈 → 换项目方向但保持基础工作不动
- **恶化信号**：财务再次吃紧/心理状态恶化 → 触发止损，全力保住基础工作

#### 阶段四：转型期（第6-12个月）

如果前面顺利，这个阶段开始从"基础工作+副业"向"全职做自己的事"过渡：
- 过渡的前提条件（走代码算）：副业收入 ≥ 基础工作收入的60% 且 连续3个月稳定
- 过渡方式：先减少基础工作时长（兼职/换更轻松的工作），不直接裸辞
- 设止损线：转型后如果3个月内副业收入下降超50%，回基础工作
